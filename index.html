01 · A1 ≈ 3 h

Referencias y mutabilidad

Asignar un nombre a una lista no crea una copia: crea un segundo nombre para el mismo objeto en memoria. Modificar por un nombre cambia lo que ve el otro.

✕Error típico 
a = [1, 2, 3]
b = a          # mismo objeto
b.append(4)
print(a)       # [1, 2, 3, 4]
✓Correcto 
a = [1, 2, 3]
b = a.copy()   # objeto nuevo
b.append(4)
print(a)       # [1, 2, 3]
Por qué importa

Si pasas un vector de pesos a una función que lo normaliza in place, tu vector original queda modificado sin que lo pidas. El mismo mecanismo aplica a diccionarios, arrays de NumPy y DataFrames: df2 = df no te da una copia de respaldo.

Compruébalo tú

¿Qué imprime? Piénsalo antes de ejecutarlo.

pesos = {'AAPL': 0.5, 'MSFT': 0.5}
respaldo = pesos
pesos['AAPL'] = 0.7
print(respaldo['AAPL'])

Indexación y slicing

La notación [inicio:fin:paso] excluye siempre el extremo derecho. Los índices negativos cuentan desde el final, y son la forma idiomática de tomar los últimos N elementos.

✕Error típico 
x = list(range(10))

x[2:8:3]       # ¿[2,3,4]? ¿[2,5,8]?
               # No: es [2, 5]
x[len(x)-5:]   # funciona, pero torpe
✓Correcto 
x = list(range(10))

x[2:8:3]       # [2, 5] — el 8 se excluye
x[-5:]         # últimos 5
x[::-1]        # invertido
Por qué importa

Toda ventana móvil es un slice: los últimos 60 días para estimar volatilidad, el primer 70% de la muestra para entrenar. Un error de un elemento en el corte entrena el modelo con un dato que no debía ver.

Compruébalo tú

Escribe el slice que toma los últimos 60 elementos, saltando de dos en dos.

precios = list(range(500))

03 · B1 ≈ 5 h

NumPy: broadcasting y shapes

Cuando dos arrays tienen formas distintas, NumPy las alinea automáticamente en vez de fallar. Es potente y es la fuente número uno de resultados silenciosamente equivocados.

✕Error típico 
import numpy as np

a = np.arange(3).reshape(3, 1)
b = np.arange(3)
(a + b).shape   # (3, 3)
                # esperabas (3,)
✓Correcto 
a = np.arange(3).reshape(3, 1)
b = np.arange(3)

(a.ravel() + b).shape   # (3,)
assert a.ravel().shape == b.shape
Por qué importa

Restar dos series de 3 000 precios con formas mal alineadas no da un error: da una matriz de 3 000 × 3 000 —nueve millones de números— y el promedio de esa matriz es un número perfectamente plausible que no significa nada. Verifica .shape siempre.

Compruébalo tú

¿Cuál es el shape del resultado y cuánta memoria ocupa?

precios = np.random.rand(2000, 1)
media = np.random.rand(2000)
desv = precios - media
print(desv.shape)

NumPy: álgebra de portafolios

En NumPy, * multiplica elemento a elemento y @ hace producto matricial. La varianza de un portafolio es una forma cuadrática y necesita el segundo.

✕Error típico 
w = np.array([0.6, 0.4])
S = np.array([[0.04, 0.01],
              [0.01, 0.09]])

var = w * S * w   # matriz 2x2
                  # no es un escalar
✓Correcto 
var = w @ S @ w          # 0.0244
vol = np.sqrt(var)       # 0.1562

# equivalente y explícito:
var = w.T @ S @ w
Por qué importa

σ²ₚ = wᵀΣw es la ecuación sobre la que se construye toda la optimización de portafolios. Si la calculas con *, obtienes una matriz en lugar de un número y el optimizador falla o —peor— converge a algo sin sentido.

Pandas: loc frente a iloc

loc selecciona por etiqueta del índice e incluye el extremo derecho. iloc selecciona por posición y lo excluye, como el slicing de Python.

✕Error típico 
df = pd.DataFrame({'px': range(5)})

df.loc[0:2]    # 3 filas (0,1,2)
df.iloc[0:2]   # 2 filas (0,1)
# asumir que ambas dan lo mismo
✓Correcto 
# etiquetas → loc (inclusivo)
df.loc['2024-01-01':'2024-03-31']

# posiciones → iloc (exclusivo)
df.iloc[:100]        # primeras 100
df.iloc[-20:]        # últimas 20
Por qué importa

Después de filtrar, el índice deja de coincidir con la posición: si te quedas con las filas donde el volumen es alto, el índice puede ser 3, 17, 48… Ahí df.loc[0:2] probablemente falla y df.iloc[0:2] te da las dos primeras supervivientes.

Compruébalo tú

¿Cuántas filas devuelve cada línea?

df = pd.DataFrame({'px': [10, 11, 12, 13, 14]})
alto = df[df['px'] > 11]
print(len(alto.loc[2:3]), len(alto.iloc[0:2]))

Pandas: merge y cardinalidad

Si la clave está repetida en la tabla derecha, cada fila de la izquierda se replica una vez por coincidencia. Pandas no te avisa: te devuelve más filas de las que entraron.

✕Error típico 
# df_a: 100 filas, id único
# df_b: 5 filas, todas el mismo id

out = pd.merge(df_a, df_b,
               on='id', how='left')
len(out)   # 104, no 100
✓Correcto 
out = pd.merge(df_a, df_b, on='id',
               how='left',
               validate='1:1')
# lanza MergeError si se duplica

assert len(out) == len(df_a)
Por qué importa

Duplicar filas al cruzar posiciones con precios infla la exposición que reportas. Es el error más caro de esta lista porque no se ve: los números siguen siendo plausibles. Usa validate ('1:1', 'm:1', '1:m') en todo merge de producción.

Compruébalo tú

¿Cuántas filas salen, y qué pasa si añades validate='1:1'?

Pandas: índices temporales

Con un DatetimeIndex, resample cambia la frecuencia de la serie respetando el calendario. Agrupar por número de mes mezcla todos los años.

✕Error típico 
# colapsa 2020..2024 en 12 grupos
px.groupby(px.index.month).last()

# toma el día calendario exacto:
# si cae sábado, devuelve NaN
px.asfreq('M')
✓Correcto 
px.index = pd.to_datetime(px.index)

px.resample('ME').last()   # cierre mensual
px.resample('W').mean()    # media semanal

px.resample('ME').agg(
    {'px': 'last', 'vol': 'sum'})
Por qué importa

Casi todo dato financiero llega diario y casi todo modelo lo quiere mensual o semanal. Además, distintas columnas se agregan distinto: el precio se toma al cierre, el volumen se suma, el retorno se compone. Un solo .mean() para todo es un error de contenido, no de código.

Pandas: retornos y look-ahead

pct_change() calcula el retorno simple. shift(1) mira al pasado; shift(-1) mira al futuro, y eso invalida cualquier backtest.

✕Error típico 
# diferencia absoluta, no retorno
df['px'].diff()

# mira el precio de mañana
df['px'] / df['px'].shift(-1) - 1

# señal de hoy sobre retorno de hoy
df['senal'] * df['ret']
✓Correcto 
df['ret'] = df['px'].pct_change()

# la señal de ayer opera hoy
df['pnl'] = (df['senal'].shift(1)
               * df['ret'])
Por qué importa

Esto es look-ahead bias y produce backtests espectaculares que no se pueden replicar con dinero real. Regla práctica: toda señal debe multiplicarse por el retorno del período siguiente a su observación. Si tu Sharpe supera 4, sospecha de esta línea antes que de tu talento.

Compruébalo tú

¿Cuál de las dos series de PnL es realizable en la práctica?

df['ret'] = df['px'].pct_change()
df['senal'] = (df['ret'] > 0).astype(int)
a = df['senal'] * df['ret']
b = df['senal'].shift(1) * df['ret']

Pandas: asignación segura

Encadenar dos indexaciones para asignar (df[...][...] = x) modifica una copia temporal. El DataFrame original queda intacto y solo aparece una advertencia.

✕Error típico 
# SettingWithCopyWarning
# y no modifica nada
df[df['pd'] > 0.05]['flag'] = 1

# mismo problema, otra forma
sub = df[df['pd'] > 0.05]
sub['flag'] = 1
✓Correcto 
# un solo .loc: filas y columna
df.loc[df['pd'] > 0.05, 'flag'] = 1

# si de verdad quieres una copia
sub = df[df['pd'] > 0.05].copy()
sub['flag'] = 1
Por qué importa

El fallo es silencioso: el script corre, no lanza excepción, y la marca de riesgo simplemente nunca se aplicó. Descubres el problema al revisar el reporte final, no al ejecutar.

Compruébalo tú

¿Cuántas filas quedan marcadas después de correr esto?

df = pd.DataFrame({'pd': [.01, .07, .09], 'flag': 0})
df[df['pd'] > 0.05]['flag'] = 1
print(df['flag'].sum())

Anualizar volatilidad

La varianza escala linealmente con el tiempo; la desviación estándar escala con la raíz. De ahí el factor √252 para pasar de diario a anual.

✕Error típico 
vol_anual = ret.std() * 252
# 252x demasiado grande

vol_anual = ret.var() * 252
# esto es la varianza, no la vol
✓Correcto 
vol_anual = ret.std() * np.sqrt(252)

# mensual → anual
vol_anual = ret_m.std() * np.sqrt(12)

# y el retorno sí escala lineal
mu_anual = ret.mean() * 252
Por qué importa

El ratio de Sharpe es μ / σ, y ambos se anualizan con factores distintos: el numerador con 252 y el denominador con √252. Equivocarse aquí multiplica el Sharpe por ~16 y hace que cualquier estrategia parezca extraordinaria.

Retornos logarítmicos

El retorno logarítmico es ln(Pₜ) − ln(Pₜ₋₁). Aplica el logaritmo a los precios, nunca a los retornos: estos pueden ser negativos.

✕Error típico 
# log de un número negativo → NaN
np.log(px.pct_change())

# log de una diferencia → NaN
np.log(px.diff())
✓Correcto 
r_log = np.log(px).diff()

# equivalente
r_log = np.log(px / px.shift(1))

# volver a retorno simple
r_simple = np.expm1(r_log)
Por qué importa

Los log-retornos son aditivos en el tiempo: el retorno de un mes es la suma de los diarios. Los simples no lo son, hay que componerlos. Por eso casi todo modelo de series de tiempo (GARCH incluido) trabaja en logaritmos.

Compruébalo tú

Verifica la aditividad: ¿coinciden las dos cantidades?

px = pd.Series([100, 105, 99, 108])
r = np.log(px).diff().dropna()
print(r.sum(), np.log(px.iloc[-1] / px.iloc[0]))

OLS con statsmodels

La API matricial de statsmodels no agrega intercepto. Si no lo pones tú, estimas una recta forzada a pasar por el origen.

✕Error típico 
import statsmodels.api as sm

modelo = sm.OLS(y, X).fit()
# sin constante: la recta pasa
# por el origen y beta sale sesgado
✓Correcto 
X = sm.add_constant(X)
modelo = sm.OLS(y, X).fit()
print(modelo.summary())

# o con fórmula (sí la agrega sola)
import statsmodels.formula.api as smf
smf.ols('ret ~ mkt', data=df).fit()
Por qué importa

En un CAPM, el intercepto es el alfa. Omitirlo no solo sesga la beta: elimina del modelo justamente el parámetro que querías estimar. Y a diferencia de otros errores de esta lista, scikit-learn sí agrega el intercepto por defecto, así que la costumbre traiciona.

Compruébalo tú

Estima los dos modelos y compara la beta. ¿Cuánto cambia?

rng = np.random.default_rng(42)
mkt = rng.normal(0, .01, 500)
ret = 0.0004 + 1.2 * mkt + rng.normal(0, .005, 500)

sin_c = sm.OLS(ret, mkt).fit().params
