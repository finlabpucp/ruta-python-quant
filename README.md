# Ruta Python Quant

Guía de estudio de los 12 temas de Python que asume el programa de Especialización en
Finanzas Cuantitativas (Fin-Lab, PUCP).

Cada tema corresponde a una pregunta de la autoevaluación de admisión y tiene un ancla propia
(`#a1`, `#c3`, `#d1`…) con el código del ítem en minúsculas, de modo que el formulario pueda
enlazar directamente al tema que el postulante falló.

Página publicada: https://finlabpucp.github.io/ruta-python-quant/
